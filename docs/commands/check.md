# `bookwright check`

Verifica el *toolchain* de Bookwright: confirma que el CLI y sus dependencias
están operativos.

## Uso

```bash
bookwright check
bookwright check --json
```

## Opciones

| Opción | Descripción |
|--------|-------------|
| `--json` | Emite un único documento JSON en stdout (apto para agentes). |
